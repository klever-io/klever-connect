# Expected output — `kda-mint`

```
Klever Connect — KDA Mint

Connected as klv1abcd…xyz. Requires the mint role on MTT-ABCD-1A.

Asset id          [ MTT-ABCD-1A ]
Amount to mint    [ 1000        ]
Precision         [ 6           ]

[ Mint 1000 MTT-ABCD-1A ]
```

After signing in the extension popup:

```
✓ Minted! Hash: 0x...
```

If the connected address lacks the mint role:

```
✗ insufficient permissions
```
